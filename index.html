接线与排错

一、虚拟声卡

要让别人听到变声，需要 Voicemeeter 或 VB-CABLE。装完重启电脑，设备列表里会出现虚拟设备。

二、路由

  • RVC 输出 → CABLE Input（或 Voicemeeter Aux Input）
  • QQ / 游戏麦克风 → CABLE Output（或 Voicemeeter Aux Output）
  • RVC 输入 → 物理麦克风

三、听自己

右侧「耳机监听」打开即可，不影响他人听到的声音。

四、更自然

  • 音调 ±12 起步，宁低勿高
  • 声线粗细 0～0.2
  • 检索占比 0.6～0.75
  • 输入降噪打开，采样长度 0.20～0.26

五、快捷键

Ctrl + Enter 开始 / 停止，Esc 关闭面板。
